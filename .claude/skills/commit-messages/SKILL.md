description: Read before writing commit messages.

Only human beings:
- can be credited within commit messages.
- are allowed to add a "Signed-off-by" line.

Follow the [commit message guidelines](../../../.agents/skills/commit-messages/guidelines.md) when writing commit messages.

If a contribution is being made under a differential license, also follow the [differential-licensing](../differential-licensing/SKILL.md) skill.
