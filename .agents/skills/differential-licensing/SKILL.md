---
name: differential-licensing
description: All contributions to this repository must be compatible with the Apache 2.0 license. Specifically (but not limited to), contributions cannot include code licensed under the terms of the GPL, AGPL or LGPL licenses. This contains guidance for making contributions under a different compatible license.
---
All differential contribution parts are to be indicated through the [REUSE Specification](references/reuse-spec-3.3.md). Every commit must be self-contained: licensing must be correctly indicated as of that commit alone.

The `reuse` CLI tool can help simplify compliance if available (may be available through `pipx run reuse` if not installed).
